# Icon Asset

> Status: **Implemented** (2026-11-11) — developer artwork integrated as the Android launcher icon.

## Source asset

- `icon/icon.png` — supplied by the developer (added to the repository 2026-11-10).
- 1254 × 1254, RGB PNG (opaque, no alpha channel), centered subject on a pure black background.
- The file in `icon/` is the preserved source of truth; the build never modifies it.

## Derived Android resources

Generated by `tools/generate_launcher_icons.py` (deterministic; re-runnable):

| Resource | Purpose |
|---|---|
| `res/drawable/ic_launcher_background.xml` | Solid black color drawable — the adaptive background layer (matches the artwork's own background). |
| `res/mipmap-anydpi-v26/ic_launcher.xml` | Adaptive icon: background + foreground + monochrome. |
| `res/mipmap-anydpi-v26/ic_launcher_round.xml` | Round-icon alias (identical adaptive layers). |
| `res/mipmap-{mdpi…xxxhdpi}/ic_launcher_foreground.png` | Artwork on the 108 dp canvas at each density (108/162/216/324/432 px). |
| `res/mipmap-{mdpi…xxxhdpi}/ic_launcher_monochrome.png` | White silhouette (alpha from gamma-lifted luminance) for Android 13+ themed icons. |

`minSdk` is 28, so the `anydpi-v26` adaptive definition applies on every supported
device; no legacy raster launcher icons are required.

## Geometry

Adaptive icons use a 108 dp canvas with a 66 dp centered safe zone (content there
survives every launcher mask shape). The artwork's dim-content bounding box spans
71.9% × 70.3% of the image, so the artwork is scaled to 91.8 dp and centered —
its content occupies ≈ 65 dp, inside the safe zone. Because both the artwork
background and the adaptive background layer are black, no seam is visible under
any mask.

## Manifest wiring

```xml
android:icon="@mipmap/ic_launcher"
android:roundIcon="@mipmap/ic_launcher_round"
```

The previous placeholder (`res/drawable/ic_launcher.xml`, generic vector mountains)
was removed.

## Verification

- Foreground bitmaps: corners transparent, content bbox 91.75 dp wide at xxxhdpi — measured programmatically after generation.
- Monochrome bitmaps: alpha extrema 0–255, white glyph only where artwork content exists.
- APK verification: `aapt2 dump badging` reports `application-icon` densities and the
  adaptive resource; recorded in `docs/agent/SESSION_LOG.md` for the release that
  first ships it.
