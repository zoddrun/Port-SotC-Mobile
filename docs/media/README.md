## Policy

- Only real screenshots captured from actual SotC Mobile builds may be added here.
- Captions/context must state build version, device/emulator, date, and what is shown.
- **Do not add** console gameplay images, concept art, or AI-generated images as evidence of Android port gameplay.
- Gameplay screenshots will be added only after verified native Android gameplay is running.
