> **This is not a playable port yet.** The Android host application is available for testing, but the statically recompiled game core is not part of this build. Importing the original disc image does not make the game playable.

## What this release is

The first public development preview of **Shadow of the Colossus Mobile**, a native Android port project for the original PlayStation 2 release. This release contains the Android host application: the UI, disc import/validation flow, settings, controller configuration, rendering/audio diagnostics, and the versioned boundary intended for the future native game core.

It does **not** contain a recompiled game core, game data, BIOS files, or any copyrighted game content.

## What works in this build

- Android host application installs and launches.
- Main screen with project status, game data status, and navigation.
- ISO import through Android's Storage Access Framework, including copy, validation, progress/cancellation, and atomic publish logic.
- Disc validation for the USA retail release `SCUS-97472` (`SCUS_974.72`, `KERNEL.XFF`, `MANAGER.XFF`, `GAMECORE.XFF`).
- Settings screen with rendering and audio options.
- Controller settings screen (connected-controller listing, deadzone, inversion, vibration, button mapping foundation).
- On-screen touch controls and touch layout editor code paths.
- Engine diagnostics screen: native host library loads, AAudio opens a 48 kHz stereo output stream, and EGL 1.4 initializes.
- Versioned host/core ABI boundary (`sotc_game_api.h`) for future core integration.

## What is not available yet

- No native game core is packaged (`libsotc_game.so` is absent).
- No game boot, title screen, rendering of game content, or gameplay.
- No in-game audio, input-to-game mapping, save/load behavior, or performance data.
- No ARM64 physical-device validation.
- No verified OpenGL ES 3 rendering path in the available test environment (see verification notes).

The application reports this state explicitly instead of launching an emulator or a fallback execution path.

## Installation

1. Download the APK from the release assets.
2. Allow installation from the source you used if Android prompts (Install unknown apps).
3. Install and open **Port SotC Mobile**.
4. Optionally use **Import Game** to select your own legally obtained `SCUS-97472` ISO image.

Importing a supported image validates and stores it in app-private storage. It does not enable gameplay in this release.

## Known issues

- The native game core is not implemented or packaged; gameplay is unavailable.
- The available API 28 emulator image reports OpenGL ES 2.0, so the GLES 3 rendering path could not be verified there. A GLES 3.0+ capable device or emulator is required for that check.
- ARM64 physical-device installation, performance, thermals, and lifecycle behavior are not yet verified.
- The APK is debug-signed; it is a development preview, not a production-signed build.
- The recompilation pipeline (Milestone 3) is incomplete and requires manual verification/recovery before ARM64 integration can proceed.
- Save persistence and gameplay input mapping depend on the future runtime/core.
