## What is New in v0.3.1-alpha.1

### 1. Launcher & Settings UI Overhaul
- **Fixed Button Wrapping:** Bottom navigation buttons (`IMPORT`, `SETTINGS`, `CONTROLS`) now enforce single-line text rendering (`maxLines = 1`, `softWrap = false`, `overflow = Clip`) with balanced padding.
- **Decluttered Home Screen:** Removed raw debug dump (`state.buildSummary` and raw shader diagnostics) from the launcher home view; detailed diagnostics remain accessible exclusively in `Settings -> Advanced -> Diagnostics`.
- **Status Indicator Dot:** A clean status dot (`#6BBF8A` Sage when ready, `#D99B52` Amber when disc/data import is required) paired with clean readiness headlines (`READY TO PLAY` / `IMPORT DISC TO PLAY`).
- **3-Tab Segmented HD Preset Control:** Compact `BATTERY` | `BALANCED` | `ULTRA` quality selector directly beneath the readiness card, switching active presets with 1 tap.
- **Console-Grade Aesthetic:** Warm aged brass (`#C6B282`) primary actions, matte basalt (`#0B0D10`) backgrounds, and stone ivory typography.

### 2. Edge-to-Edge Fullscreen & Immersive Presentation
- Replaced deprecated `systemUiVisibility` flags with Android `WindowCompat.setDecorFitsSystemWindows(window, false)` and `WindowInsetsControllerCompat`.
- Display cutout mode set to `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` for true edge-to-edge rendering spanning behind camera notches on modern devices.
- Performance statistics overlay hidden by default; sleek top-right telemetry appears only when explicitly toggled on in `Settings -> Performance`.

### 3. Sleek Vector Touch Controls
- Virtual controller buttons now draw true PlayStation geometric vector shapes on canvas (`△`, `○`, `✕`, `□`) instead of generic text letters.
- Double-ringed shoulder triggers (`L1`, `R1`) and pill-shaped lower triggers (`L2`, `R2`).
- Integrated `HapticFeedbackConstants.KEYBOARD_TAP` feedback for tactile button presses.
- Filtered internal Android kernel noise devices (`Virtual`, `mtk-pmic-keys`, etc.) from the Connected Controllers list, displaying `"No external controller connected · Touch HUD active"` when none is present.

### 4. Technical Constraints & Honest Status
- **5–7 FPS In-Game Bottleneck (Known Issue #13, Blocker B6):** While the host engine runs at 60 FPS, the recompiled guest loop in `libps2EntryRunner.so` experiences frame drops. Profiling and hardware optimization (VBO reuse, GS texture LRU cache) require physical device access (B4).
- **No Physical Device Evidence:** No game execution claim on hardware is made; all gates are verified via host compilation, unit tests, and APK verification.
