# SotC Mobile v0.3.0-alpha.1 — HD Presentation and Controls Preview

**Release date:** 2026-11-20
**Classification:** Alpha / HD Presentation and Controls Preview (development preview)
**Package:** `com.portsotc.mobile`
**Version name:** `0.3.0`
**Version code:** `3`

> **This is not a playable port yet.** The statically recompiled ARM64 game runtime is packaged and passes every no-device gate, but **physical ARM64 gameplay remains unverified**. No device has loaded this build. Do not interpret an installed HD pack, a diagnostics shader pass, a touch layout, or a telemetry line as proof of in-game rendering or input.

## What this release is

The third public development preview of **Shadow of the Colossus Mobile**, a native Android port of the original PlayStation 2 release through Celosia/PS2Recomp **static recompilation** (not emulation). It contains the Android host application and the packaged ARM64 recompiled runtime. It does **not** contain game data, ISO images, BIOS files, official trophy data, or RetroAchievements data.

The supported disc remains **SCUS-97472 (USA)** only. Eight other serials are recognized for honest region/refresh reporting but still fail with `KNOWN_UNVERIFIED_SERIAL`.

## What changed since v0.2.0-alpha.1

### HD shader pack (verified installer and diagnostics pipeline)

- Original GLSL ES 1.00 and ES 3.00 shader sources, a JSON manifest and an MIT license are bundled in `app/src/main/assets/shaders/`. No copyrighted textures or game assets are included.
- `ShaderPackInstaller` stages every file, verifies SHA-256 digests, writes an atomic state file and rolls back on failure. Presets are validated against the manifest before their values are published through JNI.
- `HdShaderPipeline` compiles the capability-matching variant on the render thread of the host diagnostics/ABI-v1 renderer. ES 3 sources are used only on a real ES 3 context; the ES 1.00 fallback is the compatibility floor. Program binaries, anisotropic filtering and framebuffer invalidate/discard are opportunistic and extension-gated. The diagnostics texture cache deduplicates repeated immutable uploads.
- A separate runner patch (0011) loads the ES 1.00 pack into the raylib-owned game-picture pass, wraps **only** the game-picture `DrawTexturePro`, and emits an independent `[hd-shader]` telemetry line beside the unchanged `[pace]` record. It is a no-op when no verified pack is published.

### Controls and interface

- Runner-side touch overlay: sigil rings and gold accents, a floating left stick whose center follows touch-down, right-half look acquisition, shoulder/claw/bridge grip hold mapped to the existing R1 bit, and ownership cleanup on gamepad hotplug or active-state transitions.
- Launcher and in-session settings use the Obsidian/Antique Gold visual language with English copy. All HD, grip and pacing captions distinguish immediate host-diagnostics changes from values read by the runner on its next launch.

## Known limitations

- **No physical ARM64 gameplay verification.** First boot, rendering, audio, touch ergonomics, lifecycle, saves, thermals, 16 KB device loading and on-device `[pace]`/`[hd-shader]` capture remain unverified.
- The host diagnostics HD pass is not the game renderer. The runner shader hook is compiled and host-smoke-tested, but its visual output has not been observed on a phone.
- Anisotropic filtering, program binaries and TBDR-style discard only run when the driver advertises the required extensions; a preset value is not a measured result.
- Program binaries and texture dedup are diagnostics-only; no game-texture optimization is claimed.
- The APK is debug-signed and is a development preview, not a release candidate.
