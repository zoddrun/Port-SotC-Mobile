## Milestone 5 — Runtime Integration (D18: raylib-owned NativeActivity)

- [ ] Package the runner library into the app APK (`jniLibs/arm64-v8a`).

- [ ] Pre-launch extraction — **I/O model confirmed by source read (2026-11-11)**: extract the FULL disc tree from the imported `disc.iso` into `/data/data/com.portsotc.mobile/files/disc/` using the existing `Iso9660Image` reader (one-time, cached, original filenames), and bake `PS2X_DEFAULT_BOOT_ELF=/data/data/com.portsotc.mobile/files/disc/SCUS_974.72` at configure time. Confirmed runtime behavior:
  - `main()` uses an absolute `PS2X_DEFAULT_BOOT_ELF` as-is; `PS2Runtime::configureIoPathsFromElf` then derives `cdRoot` = `hostRoot` = the boot ELF's directory, so every guest `cdrom:`/`cdrom0:` path resolves under the extraction root — no runtime patch (D18 confirmed).
  - File-content reads are directory-only: `PS2Vfs::resolveHostPath` mounts `hostRoot`/`cdRoot`/`mcRoot`; `cdImage` is NOT a VFS mount, so the ISO cannot back file reads — full extraction is required, not an ISO-backed layout.
  - Filename robustness (no special naming needed): `registerCdFile` resolves exact → case-insensitive walk → leaf-name index → loose numeric key (`;1` version suffix stripped, leading zeros collapsed within digit runs).
  - Memory cards: `mc0` is auto-created beside the boot ELF (`files/disc/mc0`); port 1 maps to sibling `mc1` — M9 save persistence targets those two directories.
  - Raw `sceCdRead` (LBN) reads: resolved first against the runtime's pseudo-LBN map (files registered as they are opened; synthetic LBNs), then read directly from `cdImage` (the ISO file) for real-disc LBNs. `cdImage` CANNOT be set on Android without a patch (no env var; `setIoPaths` has exactly one caller, `configureIoPathsFromElf`; a `:game` process would not inherit launcher-set env anyway). Plan: leave unset at first boot; if M6 logcat shows `sceCdRead unresolved LBN`, add a small patch baking the ISO path (mirroring the `PS2X_DEFAULT_BOOT_ELF` pattern) and keep the imported ISO at a fixed private path (~2.5 GiB extra storage; revisit only with M6 evidence).
- [ ] Quit handling: apply prepared `tools/android-integration/patches/0003-android-quit-graceful.patch` (`main()` returns on `__ANDROID__` so raylib's `android_main` finishes the NativeActivity cleanly — verified against the fetched raylib 5.5 source) and declare the game activity with `android:process=":game"` (fresh process per game session; the launcher process survives any hard exit).
