# Core ABI (v1)

> Status: **Implemented** (host side). `libsotc_game.so` does not exist yet —
> the pipeline that produces it is at Milestone 3
> ([pipeline status](RECOMPILATION_PIPELINE.md)). Until then the app runs its
> native diagnostics scene and states plainly that the game core is absent.

## Contract

Header: `app/src/main/cpp/sotc_game_api.h` (C, no C++ types across the boundary,
no exceptions thrown across it).

The host application (`libport-native.so`) loads a game core library named
`libsotc_game.so`. The core must export:

```c
const SOTCGameApi* sotc_game_query_api(void);
```

`SOTCGameApi` (append-only; new optional members may only be added at the end):

| Member | Signature | Meaning |
|---|---|---|
| `apiVersion` | `uint32_t` | Must equal `SOTC_GAME_API_VERSION` (`1`) |
| `queryInfo` | `const SOTCGameInfo* (*)(void)` | Static info: name, serial (`SCUS-97472`), build id |
| `initialize` | `int32_t (*)(const SOTCGameHost*, const char* gameDirectory)` | 0 = success |
| `shutdown` | `void (*)(void)` | Idempotent teardown |
| `render` | `void (*)(int32_t w, int32_t h, double frameTimeSeconds)` | Draw one frame into the host's current GLES context |
| `audioRender` | `void (*)(float* interleavedStereo, int32_t frames)` | Pull audio frames |
| `setPaused` | `void (*)(int32_t paused)` | Suspend/resume with the Android lifecycle |

The host supplies callbacks through `SOTCGameHost`: `log` (levelled), `padButtons`
(SCE pad bit mask), `padSticks` (normalized sticks), and `readGameFile` (bounded,
path-checked read from the imported game directory — rejects absolute paths,
`..`, backslashes, and colons).

## Loader behavior (`engine/game_core.cpp`)

1. `dlopen("libsotc_game.so", RTLD_NOW | RTLD_LOCAL)` — by soname, so the library
   is found in the app's read-only native library directory. Android 10+
   forbids executable code in writable app storage; a core is only ever loaded
   from the APK's packaged libraries. A missing library is a reported status,
   never a crash.
2. `dlsym("sotc_game_query_api")` must resolve; the returned table must be
   non-null, version-matched, and complete (all six entry points present).
   Any failure unloads cleanly and sets a human-readable status.
3. `initialize` runs with the host callbacks; non-zero result triggers
   `shutdown` + unload.
4. Runtime state (buttons/sticks) crosses the boundary via atomics; the frame
   and audio paths are no-ops while uninitialized.

## Producing a core

The core is generated by the Celosia/PS2Recomp pipeline from a legally obtained
disc image (see [RECOMPILATION_PIPELINE.md](RECOMPILATION_PIPELINE.md)). The
planned bridge is the ps2xRuntime runner entry adapted to this ABI; the exact
shim lands with Milestone 4/5 and will be documented here when it exists.
